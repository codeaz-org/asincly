# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the work, and don't harass
anyone — in issues, pull requests, discussions or anywhere you represent the project.

## Reporting

If someone's behaviour makes you uncomfortable, contact the maintainers privately through
a [GitHub security advisory](https://github.com/codeaz-org/asincly/security/advisories/new)
(it's private to the maintainers; mark it "Code of Conduct"), or by direct message to a
maintainer. Reports are kept confidential. Maintainers may remove content and ban people who
break this code, following the Covenant's enforcement guidelines.
