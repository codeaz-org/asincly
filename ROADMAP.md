# Roadmap

What's in Asincly today, and what's next. Ideas and votes welcome in issues.

## Shipped
- Check-ins on each person's own local schedule (daily, Mon/Wed/Fri, weekly, custom rules),
  DST-safe reminders
- Video check-ins (camera or screen + camera) that an AI turns into a draft of yesterday,
  today and blockers, which the author reviews
- Feed by day, replies, reactions, "I can help" on blockers, away periods, nudges
- Slack: digests to a channel and reminders by DM
- Hosted plans (Free / Pro), guests
- Branded HTML emails; @-mentions with a teammate picker; invitations the invitee accepts
- Security: row-level security on every request, 2FA, SSO enforcement, encrypted
  transcripts, audit log, data export and deletion

## Next
- Slack `/standup` to check in from Slack
- Installable app (PWA) with push notifications
- More AI providers (OpenAI, Anthropic, local Whisper) behind the existing interface
- Per-organization branding
- Microsoft sign-in, restricted to single-tenant configurations

## Later
- Calendar integration for check-in windows
- Jira / Linear links on check-in items
